### Desafio:

Desenvolver uma API contendo os seguintes endpoints:

- Cadastro de clientes (CPF, RG, Nome, Idade, Email, Login e Senha)

- Login de usuário

- Atualização de dados cadastrais (permitindo alterar um ou mais campos)

- Exclusão de usuário (física ou lógica)

- Listagem de todos os usuários

- Criação de pedidos vinculados ao usuário (ID_USUARIO + descrição do pedido, ex: headset, mouse, etc.)

- Listagem de pedidos (geral ou por usuário)

### Requisitos obrigatórios:

- Estrutura organizada e boas práticas de código

- README com instruções de instalação, execução e uso da API

- Documentação clara dos endpoints
